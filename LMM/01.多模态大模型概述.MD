# 多模态大模型概述

## 一、基础概念
1. 多模态大模型（`Large Multimodal Model`，`LMM`）定义：以海量多模态数据（文本、图像、音频、视频、3D 点云、传感信号等）为训练语料，具备跨模态理解、跨模态对齐、跨模态生成、复杂逻辑推理能力的大规模预训练基础模型。
2. 概念区分
   - `MLLM`（`Multimodal Large Language Model`）**多模态大型语言模型**，以**大语言模型**为主体，额外接入图像、音频、视频等模态编码器，语言能力最强，非文本大多为输入侧。
     - 典型代表：`GPT-4V(ision)`、`LLaVA`、`Qwen-VL`、`Gemini`（侧重语言）
     - 核心是“会看会听”的大语言模型
   - `LMM`（`Large Multimodal Model`）**大型多模态模型**，更通用的多模态大模型，不强制以`LLM`为核心，输入输出可以覆盖各种类型。
     - 典型代表：`Gemini`（全模态）、`Flux`、`Sora`
     - 核心是全模态通用基础模型
3. 模态：指信息存在形式，常见的包括文本、图像、音频、视频、3D、触觉、传感等
4. 表征学习：旨在从原始数据中自动提取有效特征，形成计算机可理解的模态表示，以保留关键信息并促进跨模态交互与融合；负责将原始的多模态数据转换为适合模型处理的低维、稠密且富有语义信息的表示。

## 二、多模态机器学习的核心技术挑战
1. 多模态表示学习：**不同模态数据怎样表示？**对不同模态数据提取特征，学习跨模态数据的信息交互，以及多模态数据的共同表示。该问题可以分为两个子问题：
   - 联合表示（Joint Representation）：“多模态数据用于解决同一个问题，将多模态数据映射到同一个表示空间中”。（已有模态数＞特征表示，需要解决的问题数目），联合表示将多个模态的信息一起映射到一个统一的多模态向量空间。多模态数据共同为同一任务合作和融合，例如使用文字、语音、视频共同识别情感。
   - 协作（协同）（Coordination Representation）：模态数=特征表示，两种数据在两种任务之间协作。协同表示负责将多模态中的每个模态分别映射到各自的表示空间，但映射后的向量之间满足一定的相关性约束（例如线性相关）。
2. 多模态转化：**不同模态数据怎样转换？**转化也称为映射，负责将一个模态的信息转换为另一个模态的信息。常见任务包括：
   - 机器翻译（Machine Translation）：将输入的语言A（即时）翻译为另一种语言B。类似的还有唇读和语音翻译，分别将唇部视觉和语音信息转换为文本信息。
   - 图片描述（Image captioning) 或者视频描述（Video captioning)： 对给定的图片/视频形成一段文字描述，以表达图片/视频的内容。
   - 语音合成（Speech Synthesis）：根据输入的文本信息，自动合成一段语音信号。
3. 多模态对齐：**同一个实例的不同模态数据怎样表示为统一的内容？**负责对来自同一个实例的不同模态信息的子分支/元素寻找对应关系
   - 对应关系可以是时间维度的。如，将一组动作对应的视频流同骨骼图片对齐。类似的还有电影画面-语音-字幕的自动对齐。
   - 对齐又可以是空间维度的，比如图片语义分割，尝试将图片的每个像素对应到某一种类型标签，实现视觉-词汇对齐。
4. 多模态融合：**多模态数据之间如何联合应用？**负责联合多个模态的信息，进行目标预测（分类或者回归）
5. 协同学习：**多模态数据之间如何借鉴训练、学习？**使用一个资源丰富的模态信息来辅助另一个资源相对贫瘠的模态进行学习
